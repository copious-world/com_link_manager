(async) app_message_handler(msg_obj) → {object}

Description:

  • This method is the override of the app_message_handler defined in the super class ServeMessageEndpoint.

    This message handler implements the responses to _tx_ops 'G' (get) and 'S' (set). A 'G' message that is properly setup will result in a call to the mime handler that had to be set by the application. A 'S' message that is properly setup will result in a call to the transtion handler that had to be set by the application.

    In most cases, it can be expected that the methods found in contractuals will be the handlers that are set to the parameters of this class.
